description: Gestiona cambios de requisitos en una spec existente
agent: plan
-----------

Quiero cambiar el requisito de esta spec:

$ARGUMENTS

Antes de modificar nada:

1. Lee `AGENTS.md`.
2. Lee `MEMORY.md`.
3. Lee `docs/constitution.md`.
4. Lee la `spec.md`.
5. Lee `plan.md` y `tasks.md` si existen.
6. Analiza el impacto del cambio.

Primero explica:

* Qué requisito cambia.
* Por qué cambia.
* Qué partes del plan se ven afectadas.
* Qué tareas se ven afectadas.
* Qué impacto puede tener sobre el código existente.

No modifiques código todavía.

Una vez aprobado el cambio:

1. Actualiza `spec.md`.
2. Actualiza `plan.md`.
3. Actualiza `tasks.md`.
4. Deja identificadas las tareas que deberán modificarse o repetirse.

El código solo debe modificarse posteriormente mediante la fase de implementación.
